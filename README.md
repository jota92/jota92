## CIT Hub

現在のメインプロジェクトです。

**CIT Hub** は、千葉工業大学の学生向けに、時間割・課題・学内サービス・板書カメラなどをひとつにまとめる非公式キャンパスアプリです。

- 時間割と授業詳細をすばやく確認
- manabaの課題と個人ToDoをまとめて管理
- 学内サービス、食堂メニュー、バスダイヤ、乗換案内にアクセス
- 授業ごとの板書写真とメモを整理
- iOS、Android、Mac向けの体験を改善中

詳しい情報は [CIT Hubの公式サイト](https://cithub.app/) と [リポジトリ](https://github.com/jota92/CIT-Hub) をご覧ください。

> CIT Hubは学生が開発する非公式アプリです。千葉工業大学が公式に提供するアプリではありません。
